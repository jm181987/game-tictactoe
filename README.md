# Tres en raya

Juego web de tres en raya (tic-tac-toe).

## Tecnologías

Aplicación web.

## Cómo empezar

Abre la [demostración publicada](https://jm181987.github.io/game-tictactoe). Para modificarlo, clona el repositorio y revisa sus archivos fuente.

Repositorio: https://github.com/jm181987/game-tictactoe

## Mantenimiento y seguridad

- Comprueba los requisitos y scripts disponibles antes de desplegar.
- No publiques claves, tokens, contraseñas ni archivos de entorno.
- Documenta los cambios y los problemas reproducibles mediante issues o pull requests.

## Créditos
